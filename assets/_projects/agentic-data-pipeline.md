# Agentic Data Pipeline

Ce projet est un projet fictif créé pour tester l'architecture.

Il s'agit d'un pipeline de données capable de s'auto-corriger grâce à des agents LLM spécialisés dans l'analyse de qualité de données.

## Fonctionnalités
- Détection d'anomalies temps réel
- Résolution automatique via AgentOps
- Dashboard de monitoring intégré
