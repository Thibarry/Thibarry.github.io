# Pipeline de Données Agentique

Pipeline de données capable de s'auto-corriger grâce à des agents LLM spécialisés dans l'analyse de qualité de données.

## Fonctionnalités
- Détection d'anomalies en temps réel
- Résolution automatique via AgentOps
- Dashboard de monitoring intégré
